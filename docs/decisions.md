# 아키텍처 결정 기록 (Architecture Decision Records)

> 이 파일은 **append only**입니다. 기존 내용을 수정하지 마세요.
> Architect (Terminal 1)가 주요 기술적 의사결정을 기록합니다.

## ADR 형식

```
## ADR-XXX: {결정 제목}
- 날짜: YYYY-MM-DD
- 상태: PROPOSED | ACCEPTED | DEPRECATED | SUPERSEDED
- 작성자: Terminal 1 (Architect)

### 컨텍스트
(결정이 필요한 배경/상황)

### 결정
(내린 결정의 구체적 내용)

### 근거
(이 결정을 내린 이유, 고려한 대안)

### 영향
(이 결정이 미치는 영향, 트레이드오프)
```
