# 설계 질의 (Questions)

> 이 파일은 **append only**입니다. 기존 내용을 수정하지 마세요.
> 모든 터미널이 질의할 수 있으며, Architect (Terminal 1)가 응답합니다.

## 사용법

질의 작성 시 아래 형식을 사용하세요:

```
## Q-XXX (날짜, 작성자 역할)
- Task: TASK-XXX (관련 Task가 있는 경우)
- 질문: (구체적인 질문)
- 상태: OPEN

### 답변 (날짜, Architect)
- (답변 내용)
- 상태 변경: OPEN → RESOLVED
```
