## 레이어 구조

### Presentation Layer
- 책임: HTTP 요청/응답 처리, 입력 검증
- 위치: `src/controllers/` 또는 `src/routes/`

### Service Layer
- 책임: 비즈니스 로직 처리
- 위치: `src/services/`

### Data Layer
- 책임: 데이터 영속성 관리
- 위치: `src/repositories/` 또는 `src/models/`
